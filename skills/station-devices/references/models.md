## Unsupported entries and profiles

The device index lists **Duo Max** and **Station Pro** as awaiting data, with no
dedicated Markdown page. AliceBridge also lists Module, Module 2, Elari A98,
Prestigio SmartMate, Lightcomm and Linkplay profiles, and server profiles for both
JBL models, Max, Mini 2, Mini 3 and Mini 3 Pro, without an established full run.
Additional named OTA profiles have unknown retail mapping or disabled downgrade.
None extends this matrix's support. An available image is not a safe image.

## Conflicts and scope boundaries

- **Dropbear architecture conflict:** [SSH](https://hackalice.me/start/ssh/) and the
  Midi page describe the supplied binary as armhf;
  [toolchain](https://hackalice.me/internals/toolchain/) lists it as AArch64. Inspect
  the selected release's ELF metadata; do not choose a binary from either label alone.
- **TLS claims conflict in scope:** [older pitfalls](https://hackalice.me/internals/gotchas/)
  describes configurable plaintext endpoints and no pinning on a sampled Lite.
  Fiero Hi reports pinned voice endpoints, and
  [Plum](https://hackalice.me/start/retail-ca/),
  [Bergamot](https://hackalice.me/start/retail-ca-mini3/), Mini 2 and Orion report
  rejected certificate chains. Do not weaken TLS as a diagnostic shortcut.
- **DNS support tables disagree:** [root guide](https://hackalice.me/start/root/)
  marks Max as verified, while both Max pages report an unprivileged shell and
  elevation only until reboot; its local-server table lists Max as both verified
  and untested. Keep method and build attached to every claim.
- **Android package statements lag access evidence:**
  [packages](https://hackalice.me/start/packages/) groups Android models as lacking
  root, while [AliceBridge](https://hackalice.me/start/root-android/) documents
  a first-generation boot route. That does not validate Entware on Android.
- **The two Max pages disagree on hardware:** data-partition size, the DAC's I2C bus
  and several listed chips differ. The Zigbee page explains that one image carries
  drivers for unfitted chips; a module list is not a parts list.
- **Mini 3 persistence is not Mini 3 Pro persistence,** and Pickle differs by build:
  factory-12 keeps rootfs edits, current builds keep only data. Immutable file
  attributes do not protect a reflashed volume.
- **AirPlay is not transparent by default:** [recipe](https://hackalice.me/recipes/airplay/)
  has a light receiver that leaves the station alone, a repair script whose hooks
  stop Quasar during playback and a Station 2 bundle that halts Alice's media daemon.
  None is approved implicitly by a request to install AirPlay.

Hardware limits here are community observations, not manufacturer specifications.
No firmware, boot image, kernel module, exploit, certificate or private key is
distributed with this reference.
